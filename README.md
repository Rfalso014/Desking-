# Gestor de Descargas

App de escritorio (Python + PySide6) y extensión de navegador para descargar y organizar contenido multimedia.

## Preparar el entorno (Windows, PowerShell)

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
pytest
```

Ver `docs/REGISTRO.md` para decisiones, versiones y estado.
